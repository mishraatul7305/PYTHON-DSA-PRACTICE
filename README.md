# Python DSA Practice 🐍

This repository contains my Python Data Structures and Algorithms (DSA) practice problems as I improve my problem-solving and coding skills.

## 📚 Problems Covered

1. **Two Sum** – Find two numbers that add up to a target.
2. **Maximum Subarray** – Find the maximum sum of a contiguous subarray using Kadane's Algorithm.
3. **Rotate Array** – Rotate an array to the right by `k` positions.
4. **Quick Sort Partition** – Partition an array using a pivot and two-pointer logic.
5. **Reverse Array** – Reverse an array using two pointers.
6. **Array Reversal Practice** – Practice swapping elements and updating pointers.
